**Course:** Nand to Tetris – I (ETCCNT301)  
**University:** K.R. Mangalam University

**Personal Number (K):** 46

## 1. Project Overview

The objective of this project is to make the Hack Computer display a black rectangular box on the screen while a keyboard key is pressed.

The project is divided into three parts:

- **Part A:** Building the Hack Computer using HDL.
- **Part B:** Developing a two-pass Hack Assembler using Python.
- **Part C:** Writing a Hack Assembly program to draw and erase a rectangle.

## 2. Personal Number Calculations

My personal number is K = 46.

- K mod 3 = 1
- K mod 4 = 2
- Starting Row = 46
- Box Height = 20 rows
- Box Width = 16 × (2 + 1) = 48 pixels
- Screen Words Per Row = 3
- Starting Screen Address = 17856

### 3. Project Files

| File Name | Description |
|---|---|
| CPU.hdl | Hack CPU implementation |
| Memory.hdl | Memory implementation |
| Computer.hdl | Complete Hack Computer |
| assembler.py | Python-based Hack Assembler |
| Box.asm | Assembly program for drawing the box |
| Box.hack | Machine code generated by the assembler |

## 4. Part A – Building the Computer

The computer is implemented using three HDL files:

- CPU.hdl
- Memory.hdl
- Computer.hdl

These files connect the CPU, memory and program ROM to form the complete Hack Computer.

## 5. Part B – Python Assembler

The Python assembler converts Hack Assembly instructions (.asm) into 16-bit binary machine instructions (.hack).

Features:
- Two-pass assembly process.
- Label and symbol handling.
- Variable allocation starting from RAM address 16.
- Conversion of A-instructions and C-instructions.
- Line-numbered error messages for invalid instructions.

**K-based extra feature:** Since K mod 3 = 1, the assembler displays a clear error message with the line number when an invalid instruction is encountered.

## 6. Part C – Box Drawing Program

The Box.asm program draws a black rectangle on the Hack screen.

Expected behaviour:
- When a key is pressed, the black box appears.
- When the key is released, the box disappears.

Box specifications:
- Starting row: 46
- Height: 20 rows
- Width: 48 pixels

The assembly program is converted into Box.hack using the custom Python assembler and can be executed in the CPU Emulator.

## 7. How to Run the Project

### Requirements
- Python 3
- Nand2Tetris Hardware Simulator
- Nand2Tetris CPU Emulator

### Run the Python Assembler

```bash
python assembler.py Box.asm
```

This generates the Box.hack machine code file.

### Run the Box Program

1. Open the Nand2Tetris CPU Emulator.
2. Load the generated Box.hack file.
3. Run the program.
4. Test the keyboard input to observe the box.

### Test the HDL Files

Open the HDL files in the Hardware Simulator and run the official test scripts provided with the Nand2Tetris course.

## 8. Conclusion

This capstone project demonstrates the working of computer architecture, HDL-based hardware design, assembly language programming and assembler development.

It combines hardware and software concepts to demonstrate how the Hack Computer processes instructions and interacts with memory, screen and keyboard.
